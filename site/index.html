SYSTEM / 06

One loop. Six layers.

From raw signals to measurable behavior, each layer contributes a distinct part of the Agent system.

01 / DATA

Behavior & context

User events, item graphs, session context, creator supply.

02 / MODELS

Understand & generate

User/item encoders, generative recommender, ranking policy.

03 / TRAINING

Optimize preferences

Preference learning, long-term rewards, exploration policies.

04 / INFERENCE

Candidate to feed

Candidate generation, constrained reranking, online serving.

05 / HARNESS

Supply & controls

Inventory, freshness, experimentation, creator supply tools.

06 / EVAL

Long-term value

Relevance, diversity, retention, ecosystem health.

NON-NEGOTIABLES

Built to stay trustworthy.

The Agent is only as useful as the boundaries around it are clear.

01

Protect the user

Engagement cannot override long-term value and well-being.

02

Design for the ecosystem

Recommendations must respect creators, supply, and diversity.

03

Keep feedback visible

Exploration and feedback loops remain inspectable.
